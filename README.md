# 🏫 桃園市立會稽國中 115學年度第1學期 課表查詢系統 (含特教與資優教師)

本專案為 **桃園市立會稽國中 115-1 課表查詢系統（含特教與資優教師課表）**，由 AI 自動解析學校 PDF 課表（班級課表、教師課表與特教老師課表）並轉換為現代化響應式網頁系統。

## 📁 專案檔案結構
```
timetable--11501-01-master/
├── index.html              # 系統入口與前端版面佈局
├── style.css               # 樣式表（含 RWD 響應式與光影特效）
├── app.js                  # 核心邏輯（課表渲染、CSV/JSON 解析、過濾器）
├── data.js                 # 內嵌備援資料庫（支援本機雙擊開啟免伺服器）
├── config.js               # 系統設定檔（會稽國中校名、學期路徑、上下課時間）
├── timetable_11501.csv     # 115-1 全校教師課表資料庫（77位教師，含8位特教/資優/外籍教師）
├── homerooms_11501.json    # 115-1 全校班級導師對照檔（22個班級）
├── 啟動課表系統.bat        # 本機一鍵啟動伺服器批次檔
├── 404.html                # 靜態路由 404 頁面
└── README.md               # 專案說明文件
```

## ✨ 系統功能與特色
1. **新增特殊教育與資優教師查詢**：
   - 教師查詢中新增「特殊」科目分類。
   - 支援 8 位特殊/資優/外籍教師課表查詢：**外籍教師、陳泓儒、陳奕哲、陳怡妏、江蕙君、張堡琳、許庭珊、楊亞婷**。
2. **班級課表查詢**：
   - 支援七年級（701~707）、八年級（801~807）、九年級（901~908）快速選班查詢與導師姓名標註。
   - 雙向點擊跳轉（點教師看教師課表，點班級看班級課表）。
3. **支援免伺服器本地直接開啟**：
   - 支援直接雙擊 `index.html` 或點擊 `啟動課表系統.bat` 啟動。

## 🚀 本地預覽方式
- **方式一**：直接雙擊開啟 `index.html`。
- **方式二**：雙擊執行 `啟動課表系統.bat`。
- **方式三**：執行 `python -m http.server 8000` 並前往 `http://localhost:8000`。
